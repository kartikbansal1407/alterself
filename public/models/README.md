# Pose model asset

pose_landmarker_lite.task is the MediaPipe Pose Landmarker Lite float16 model,
version 1, downloaded from:

https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

It is served from the AlterEgo origin so a workout does not need to request a
third-party model host. The model is a baseline engine for the Beta experience
and is replaceable through the application-owned PoseEngine interface.
